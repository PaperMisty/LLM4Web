# LLM4Web AI Assistant

基于 Chrome Manifest V3 的轻量级、零依赖流式 AI 侧边栏/悬浮面板助手。支持 **SiliconFlow (硅基流动)** 与 **DeepSeek 官方** API，完美融合了 DeepSeek-R1 的思考过程展示，并支持本地离线的 Markdown 排版和 LaTeX 数学公式渲染。

---

## ✨ 核心特性

### 1. 三种呈现模式 (Display Mode)
根据您的工作流自由切换：
*   **页面内悬浮面板 (inPage - 默认)**：
    *   通过网页内 `iframe` 直接注入到当前标签页中，不依赖浏览器窗口焦点，点击主网页空白处**绝对不会退隐到大窗背后**。
    *   支持网页内**自由拖拽定位**，且自动将坐标保存在 `chrome.storage.local` 中，跨标签页或下次打开时自动恢复位置。
*   **悬浮小窗口 (Popup Window)**：
    *   点击扩展图标会弹出一个独立的精美 Chrome 窗口。
    *   默认贴合在您当前活动浏览器窗口的右侧边缘。
    *   **尺寸与位置记忆**：当您拖拽拉伸该小窗口改变其大小时，系统会实时记住它的 `width`, `height`, `left`, `top`，再次开启时精准复原。支持多个 Popup 独立多窗口并行对话。
*   **侧边栏模式 (Side Panel)**：
    *   Chrome 原生的 Side Panel 侧边栏，完美嵌入在浏览器侧边，不占用网页本身的显示区域。

### 2. 滑词取义 (Select to Explain)
*   **多模式并列按钮栏**：在网页上选中文本时，光标右下方会浮现一个小巧精美的“小药丸”操作面板，并列提供 **“⚡ 简易”**、**“🧠 中等 (默认)”**、**“🎓 复杂”** 三个按钮。
    *   **⚡ 简易**：将模型生成长度限制在 50 tokens 左右，直奔主题。
    *   **🧠 中等**：将模型生成长度限制在 200 tokens 左右，提炼核心要义。
    *   **🎓 复杂**：不设长度限制，允许模型完全自由发挥、进行深度学术剖析。
*   **50 字网页上下文智能注入 (Context Capture)**：系统在捕获到选区的瞬间，会使用克隆 HTML Range 的方式自动提取**当前选区前面最近的 50 个字符**和**后面最近的 50 个字符**作为上下文背景。这能帮助大模型完美理解该术语/片段在网页当前段落中所处的真实语境，避免断章取义。
*   **提示词 & 上下文 UI 隐藏隔离**：所有的网页前文/后文上下文、以及模式约束提示词仅在 API 请求构建时才会合并装载。在用户的对话聊天气泡及持久化历史中，**只会干净地渲染出划选的原生文本卡片**（形如 `📖 解释选中文本：\n"..."`），确保界面干净纯洁。
*   如果是在 Chrome 系统页面（如 `chrome://`）、空白新标签页或 Chrome 应用商店等受保护网页上，根据浏览器安全规范会自动忽略脚本注入，防止权限滥用。

### 3. 本地离线 Markdown + LaTeX 数学公式渲染
*   **100% 离线运行**：所有解析库（`marked.js`、`katex.js` 和样式文件）均存放在本地 `lib/` 目录下，不加载任何外部 CDN 资源，保证隐私安全。
*   **四重公式匹配隔离算法**：完美兼容 `$$...$$`、`$...$`、`\[...\]` 和 `\(...\)` 四大主流大模型 LaTeX 输出语法。先将公式提取并保护为无冲突的占位符，再将文本送去 marked 编译表格、列表、标题，最后还原 KaTeX 矢量符号，消除了 Markdown 元字符（如 `_` 和 `*`）对 LaTeX 公式的破坏。
*   **移动端与窄屏适配**：针对侧边栏和悬浮窗等窄视口进行了针对性 CSS 优化，表格与块级公式支持局部横向滚动，防止撑破聊天气泡。

### 4. API 提供商解耦 & 思考参数完美分流
*   **DeepSeek 官方**（`provider === "deepseek"`）：在开启思考模式时，发送官方最新规定的顶级字典传参：
    ```json
    "thinking": {
      "type": "enabled"
    }
    ```
*   **硅基流动**（`provider === "siliconflow"`）：发送顶级布尔值传参：
    ```json
    "enable_thinking": true
    ```
*   **自定义 (Custom)**：支持任何符合 OpenAI 标准兼容的第三方大模型 API 地址及模型。

### 5. 极客级窗口关闭策略 (Close Strategy)
*   **主动关闭才关闭 (默认)**：小窗口悬浮在屏幕最前，方便一边看资料一边对照小窗笔记。
*   **点击其他区域自动关闭 (失焦关闭)**：小窗失去焦点（如点击了浏览器其他网页或桌面）时自动关闭销毁，即用即走。

### 6. 六套精美配色主题 (Theme Schemes)
通过 CSS 变量架构实现无缝一键换肤，可在设置页进行实时换肤效果预览：
*   🌼 **柔和暖米淡黄 (默认主题)**：米黄护眼底色，搭配温暖棕褐文字，复古书本质感，适合长时间沉浸式查阅。
*   🌪️ **极简质感银白**：现代苹果银灰亮色 Mica 风格，高雅大气。
*   🌐 **极光数码科技青**：深邃蓝底配以高亮青色霓虹，赛博朋克科技感十足。
*   🔮 **浪漫薰衣草紫**：深紫底色配上梦幻香芋粉紫。
*   🌲 **优雅深林黛绿**：黛绿偏暗黑风格，静谧温润。
*   🎱 **经典深邃磨砂黑**：极简纯黑，极低视觉负担。

## 🛠️ 安装运行指南

1.  **下载/克隆本项目**到本地目录。
2.  打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并按回车。
3.  在扩展程序页面右上角，开启 **"开发者模式" (Developer mode)**。
4.  点击左上角的 **"加载已解压的扩展程序" (Load unpacked)** 按钮。
5.  选择本项目的根目录（即包含 `manifest.json` 的文件夹）进行加载。
6.  固定插件：点击浏览器工具栏的拼图图标，将 **LLM4Web AI Assistant** 固定在工具栏。

---

## ⚙️ 快捷配置

1.  点击插件图标，在面板头部点击 **设置齿轮** 图标打开设置页。
2.  **免手动配置的极速导入 (开发测试)**：
    *   如果您在项目根目录下放了包含测试密钥的 `.env` 文件，设置页面头部会自动展示快捷导入条，点击 **“一键导入”** 即可瞬间加载密钥。
3.  点击 **“🔌 测试连接与推理”**：
    *   系统会自动向对应接口发送 1-Token 测试包，并根据返回体是否带有 `"reason"` 字符来**自动探测并缓存该模型是否支持“思考/推理能力”**。
    *   保存设置后，即可在主聊天面板中智能显隐“思考”开关。

## 📂 项目结构

```text
├── manifest.json       # 扩展清单文件
├── background.js       # Background Service Worker (代理请求、窗口管理、失焦监听)
├── content.js          # Content Script (捕获划词选区、注入页面内 iframe 面板)
├── content.css         # 页面内悬浮按钮与拖拽遮罩的 CSS 样式
├── panel.html          # 侧边栏/悬浮窗聊天主界面
├── panel.js            # 对话流式拼接、状态管理、Markdown与公式解析核心逻辑
├── panel.css           # 聊天气泡、思考卡片与六套配色方案的 CSS 变量系统
├── options.html        # 设置页面 HTML
├── options.js          # 设置页面交互、.env 导入与测试连接逻辑
├── options.css         # 设置页面的配色与排版
├── icons/              # 16, 48, 128 像素的扩展图标
└── lib/                # 本地离线引用的 marked.min.js, katex.min.js 及 katex.min.css
```
